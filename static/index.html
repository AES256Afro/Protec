ADD A DEVICE

Enroll your first Linux agent

This token enrolls one device and expires in 15 minutes. Closing this window clears it from the page.

From the Protec checkout on the device, run:

python3 -m protec.agent --enroll

Paste the token at the prompt. The foreground agent sends inventory every 30 seconds. This local prototype connects to 127.0.0.1:8765.

Remote fleet enrollment requires a hardened HTTPS deployment. Administrator privileges are reported, but this agent does not elevate or change system settings.
